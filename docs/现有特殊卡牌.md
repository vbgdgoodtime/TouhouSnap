# 现有特殊卡牌

> 与 `data/cards.js` 的 `SPECIAL` 保持同步。token **不入人物卡牌库、不出现在图鉴的「普通卡牌池」**，只在图鉴**「衍生卡牌池」**里可见；按形态分四类：
> - **落场型**（石块、厄运、龙玉）：落地即翻开、占用格位，吃增益/削弱/区域加成/持续效果，可作「摧毁」/移动目标；
> - **手牌衍生物**（废弃列车、极限火花）：入手后像普通卡手动暗出，翻面结算自身效果（自带 `k`），用后不回牌库；
> - **牌库衍生物**（冰块）：被**洗入某一方牌库**（隐藏区）——不翻开、不占格位、不结算任何效果、不进 `fieldQueue`，日后该方**抽到手、再暗出翻开**时才按普通卡走常规流程；
> - **场地占位型**（隙间）：随场地固定生成、纯静态，`un` 绝对不可操作——无能量无战力，不可移动、不可被摧毁或被任何效果修改。
>
> **法术 token**（`spell: true`）只有能量花费与「揭示」效果，「威力」栏记 0（卡框不显示战力，标「法术 · 无战力」）。`give` 塞入手牌者需手动暗出（暗出 → 翻牌揭示 → 消散）；`placeToken`／分身 `clone` 落场生成者**等同手打一张法术**——先结算自身揭示，随即**自行消散**、不占格。法术不吃战力增减/区域加成，也**不被 `dw`/`dwh`/`dwc`/`mv`/`gift` 选为目标**。见 `docs/现有机制.md` §1「法术」段与 §3。
>
> **衍生物池**（帕秋莉法术池、极限火花、辉夜神宝 6 条、冰块）**不入牌库、不进图鉴人物卡档**；只在图鉴**「衍生卡牌池」**（与「普通卡牌池」平级的顶层切换，池内按 1~6 费分档）与对应人物的「衍生卡牌」面板可见，入手后需手动暗出。帕秋莉法术池只由帕秋莉·诺蕾姬回合开始（`fx.turnStart` → `k:'drawSpell'`）随机抽入手牌（可重复抽到同一张；满 7 张则加入失败）；辉夜 6 条只由蓬莱山辉夜（5 费/8 战力）揭示走 `give.pool` 取出——5 张神宝（无限生命泉/火蜥蜴之盾/佛体金刚石/耀眼之龙玉/蓬莱的玉枝）**不放回随机抽 2 张（互不相同）**入手牌（满 7 张则加入失败/部分加入）；⚠️ 龙玉**不属于神宝池**。开发者「🎯 指定卡牌」中极限火花与辉夜两张法术可加入手牌，其余 token 仅可查看。
>
> 桑尼米尔克的揭示（`costUp`）只改对方手牌里既有卡的费用、**不生成 token**，本表无对应条目。
