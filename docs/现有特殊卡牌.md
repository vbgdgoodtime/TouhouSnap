# 现有特殊卡牌

> 与 `data/cards.js` 的 `SPECIAL` 保持同步。
> 特殊卡牌（token）**不入人物卡牌库、不出现在图鉴的「普通卡牌池」**（只在图鉴**「衍生卡牌池」**里可见），
> 一般由地形或人物效果按键名生成；通常不参与洗牌/抽牌，但按形态分**四类**：
> - **落场型**（直接生成到区域，如石块、厄运）：落地即翻开、占用格位，会被增益/削弱/区域加成/持续效果影响，可作为「摧毁」/移动目标；
> - **手牌衍生物**（加入手牌后像普通卡打出，如废弃列车；**v177 起含法术「极限火花」**）：可暗出、翻面时结算自身效果（自带 k），用后不回牌库；
> - **牌库衍生物**（**v184 起**：被效果**洗入某一方牌库**，如冰块）：进的是**隐藏区牌库**——**不结算任何效果**（不翻开、不占格位、不进 `fieldQueue`），日后被该方**抽到手、再暗出翻开**时才按普通卡走常规流程；
> - **场地占位型**（随场地固定生成、纯静态，如隙间）：`un` 绝对不可操作——无能量无战力，不可移动、不可被摧毁或被任何效果修改。
>
> 🪄 **v170 · 衍生物法术**：`SPECIAL` 里的**法术 token**（`spell: true`）也收录于本表——它**只具有能量花费与「揭示」效果**，
> 「威力」栏记 **0**（卡框不显示战力，标「法术 · 无战力」）。两种入口：① **手牌衍生物型**（由 `give` 塞入手牌）：仍需手动打出，
> 走正常「暗出 → 翻牌揭示 → 消散」；② **落场生成型**（`placeToken` / 分身 `clone`）：**等同手打一张法术**——先结算它自身的揭示，
> 随即**自行消散**（不会留在场上占格）。法术不吃任何战力增减/区域加成，也**不被 `dw`/`dwh`/`mv`/`gift` 选为目标**；
> 完整口径见 `docs/现有机制.md` §1「法术」段与 §3 特殊卡规则。
>

> 由**重做后的「琪露诺」**（1 费 / **2 战力**，揭示 `shuffleIn`）**洗入对手的牌库**，

> 再暗出翻开**时才按普通卡走常规流程（1 费 / 0 战力白板，占 1 格，可被增益/削弱/摧毁/移动）。

> 「手牌满不抽牌」卡住后续抽牌）；**张数无上限**（牌库没有 7 张上限，故「手牌满则失败」不适用）。
> **公开**：日志点名 + 轻量演出（对手侧栏「牌库 N 张」青蓝闪光 + 「🃏 洗入卡组 ×1」气泡）。

> ⚠️ 它**不属于任何「池」**（不被 `give.pool` / `drawSpell` / `gather` 等按池抽取的机制引用），
> 唯一生成来源是琪露诺的 `shuffleIn`。机制口径见 `docs/现有机制.md` §1「洗入卡组（`shuffleIn`）」段；
