# 现有人物卡牌

> 与 `data/cards.js` 的 `POOL` 保持同步。人物卡按费用放入牌库抽选池（`POOL`）：**1~6 费**会被玩家兜底牌库（`DECK_CURVE`）/ 对手曲线（`AI_DECK_CURVE`）的随机抽卡抽到；**0 费**暂不入洗牌；**7 费**只存在于 `POOL[7]`、**8 费**只存在于 `POOL[8]`——两条随机曲线都不含 7/8 费，这两档**只能通过「卡组设置」自建卡组带入**。全部人物卡都会出现在图鉴中。共 **56** 张。
> **法术卡**（`spell: true`）也收录于本表：法术**只具有能量花费与「揭示」效果**，表中「威力」栏记 **0**（卡框不显示战力，标「法术 · 无战力」）；法术可入卡组、会被随机曲线与 AI 抽到，暗牌占 1 格、揭示瞬间仍占格，揭示效果结算完后**自行消散**（口径见 `docs/现有机制.md` §1「法术」段）。
> ⚠️ **0 费组为空**：`POOL[0]` 空桶保留；牌库曲线（1~6 费）本就与之无关；图鉴 /「指定卡牌」/ 卡组页的费用筛选为「0-1 费」合档，不受影响。
> **阵营**：卡牌 `g` 字段标注所属（`scarlet` 红魔馆、`light` 光之三妖精）；红魔馆区域（`aff`）会为 scarlet 角色常驻 +2。现 scarlet 成员：红美铃 / 十六夜咲夜 / 帕秋莉·诺蕾姬 / 芙兰朵露·斯卡蕾特 / 蕾米莉亚·斯卡蕾特；**小恶魔（红魔馆）未实装**，占位待后续加入。现 `light` 成员：桑尼米尔克 / 露娜·切露德 / 斯塔萨菲雅（暂无地形为其提供 `aff` 加成）。其余卡无 `g`：不吃任何 `aff` 加成，也不会被「三妖精集结」的 `gather` 抽到。
> **效果类型**（`k` 字段）：
> - 白板：无揭示效果。
> - `bf` 同区友军增益 / `de` 同区敌方削弱 / `ba` 双方同增 / `bl` 落后自增（也作时机效果复用：蕾米莉亚·斯卡蕾特 → `fx.turnEnd` 每回合末判一次）。
> - `dw` 摧毁敌方最弱 / `dwh` 摧毁敌方最强（**并列最高时随机挑一张**）/ `dwb` 摧毁本区双方最弱随机一张 / `dwc` 按印刷费用全场摧毁（妖精大战争：摧毁双方场上所有 1 费已翻开牌，含 1 费 token、不含暗牌与法术，逐区受免摧毁保护）。
> - `spawn` 添加石块 / `spawnO` 本区敌方侧生成特殊卡 / `spawnS` 本区自己一侧生成特殊卡（另有 `fill: true` 写法：填满该侧、消散后正好铺满）/ `spawnMine` 己方每个区域（含本区）各生成特殊卡（耀眼之龙玉）/ `clone` 另两区自己一侧生成分身。
> - `deAll` 敌方全场（三区）已翻开卡牌各 −N（蓬莱的玉枝；非随机分配）。
> - `tkBuff` 标记卡增幅：己方/全场同 `tk` 标记卡永久 ±N，可先落场生成。
> - `give` 加入手牌衍生物（雾雨魔理沙 → 法术「极限火花」；亦支持 `pool` 写法——蓬莱山辉夜从 5 张神宝里随机抽 2 张，见 `docs/现有特殊卡牌.md`）。
> - `xform` 区域变形 / `switch` 换边到对方一侧 / `gift` 本区己方最低已翻开卡换边到对方 / `morph` 变身成对方手牌随机卡复制体 / `mv` 移走 / `oc` 对方同区落牌自增 / `shift` 己方左端已翻开卡整体右移（填满为止）。
> - `costUp` 对方手牌随机一张能量消耗 +1（本场战斗有效）/ `energyNext` 自己下回合额外获得能量。
> - `gather` 集结：三区自己一侧各生成 1 张阵营成员并结算其揭示，随后己方场上已翻开的同阵营 +N 战力。
> - `shuffleIn` 洗入卡组：把指定牌 n 张洗入自己或对手的牌库并重洗（现由琪露诺使用 → 向对手牌库洗入 1 张「冰块」）。
> - `discard` 弃牌：把牌从**手牌**移出 → 进该牌**归属方**的**弃牌池**；与「摧毁」分工不同——**摧毁只管场上、弃牌只管手牌**，故不触发任何摧毁类机制。写法 `discard: { n, to, pick, card, cost }`：`to` 缺省弃自己、`'opp'` 弃对方；`pick` = `'random'`（缺省）/`'right'`（最右侧）/`'left'`（最左侧）/`'maxCost'`（取印刷费用 `def.c` 最高的一张，**并列最高时随机**）；`card`/`cost` 按卡名与**印刷费用**筛选。现由「莉莉黑」（1 费 / 3 战力）使用 → 丢弃自己最右侧的 1 张手牌；「小野塚小町」（3 费 / 5 战力）使用 → 丢弃自己手牌中印刷费用最高的一张。另有可选子句 `give`：弃牌**真的发生之后**按**被弃牌的印刷费用 `def.c`** 为**施放方自己**加入手牌衍生物（`powerFromCost: true`；弃牌落空则不结算；进手牌、手牌上限 7 张照常约束、仍需手动暗出）——现由「姬虫百百世」（2 费 / 2 战力）使用 → 随机弃自己 1 张手牌，并加入 1 张战力＝该卡费用的「石块」。
> - `reviveDiscard` 复活弃牌池：把**自己一方**的**弃牌池**里**所有「角色卡牌」（＝非法术的牌）**以**随机顺序**逐张复活到**随机区域**——每张牌只在“已开放且该侧放得下”的区域里随机（**不会**因掷到满区而复活失败）、落地即翻开并**逐张重新结算其自身揭示**；**法术不参与复活**、留在池里。现由「四季映姬」（6 费 / 6 战力）使用 → 若可能，将你所有被丢弃的角色卡牌，以随机顺序复活到随机区域中。
> - `retrigger` 揭示再触发：把**此牌所在区域**里**自己一侧、已翻开**、带 `k` 的卡牌（**四项排除＝自己 / 法术 / `un` 占位卡 / 同为 `retrigger` 的卡**——最后一项**防死循环**）的「揭示」效果**各再结算一次**，逐张走 `applyEffect`（**所有揭示键都会重跑**，含落场 token 的揭示）；**只重触发「揭示」**——`fx` 时机效果（`turnStart`/`turnEnd`/`gameEnd`/`handEnd`）、持续 `og`、`surv`/`phx`/`prot`/`ind`/`fly` 与地形类 `gamble`/`gust` **一律不触发**；只作用于**结算那一刻已翻开**的卡（本区同侧**后翻开的暗牌错过**本次、不补）；顺序＝**本区放置先后**，每张结算前**重读其当前所在区域**（被 `shift`/`mv`/换边挪走仍触发一次、按新区域结算；已被摧毁/回手则跳过）；非“摧毁”/非增减/非放置；正常翻牌流程**逐张推进、相邻两张停 500ms**（非翻牌路径走同步版）。现由「东风谷早苗」（5 费 / 6 战力）使用 → 使此牌所在区域的其他己方已翻开卡牌的「揭示」效果各再触发一次。
> **卡级机制**（与 `k` 并列的字段）：持续 `og`（按 `tk` 标记匹配 token，也支持按印刷费用 `cost` 匹配：克劳恩皮丝 → 己方场上该费用的卡牌）、法术 `spell`、防摧毁 `surv`、自身不可摧毁 `ind`（佛体金刚石：判定式免疫——摧毁判定照常把它算进去，落在它身上则摧毁失败、判定结束、不改打其他牌；只保护它自己）、游戏开始时 `gs`（哆来咪：只要开局时它在你的卡组/牌库里就触发、整局永久——从普通卡牌池**不放回**随机洗入 10 张牌 + 本局每回合最大能量 +1）、凤凰重生 `phx`、终局离场 `leave`（机制保留为预留，**当前无使用者**）、大体积占格 `occ`、区域持续免摧毁 `prot`、费用随摧毁递减 `costDown`（纯狐：本场战斗中双方每有一张牌被摧毁，此牌能量消耗 −1，下限 0 费）、放置条件 `playReq`（大鲶鱼：`playReq: { tk:'rock', n:4 }` —— **只在“从手牌打出”那一刻检查**，己方场上已翻开的「石块」< 4 张就打不出来；**打出后不再追踪**，石块之后被摧毁/移走也不移除它；复活/变身/落场生成等其它上场路径不受限）；**时机效果 `fx`**（`turnStart`：帕秋莉的回合开始抽法术；`turnEnd`：无限生命泉的回合结束 `bf +2`；`handEnd`「手牌回合结束」——只结算“回合结束时仍在手牌里”的牌，现由稗田阿求使用）。其余见各卡效果文本。
