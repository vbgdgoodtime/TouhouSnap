# 历史版本记录（东方逆转）

> 本文件是**历史变更记录的唯一存放处**（v168 起从 `docs/GAME_REFERENCE.md` §5 迁出，并**精简压缩**）。
> - **收录范围**：**v1 – v167** 逐版本记录（v167 及以前为从 GAME_REFERENCE 简化的历史档案，**不再追溯改写**）；
>   **v168 起不再逐版本记录**——地形 / 人物卡 / 特殊卡 / 引擎机制的新变化写进各自**专项文档**
>   （`docs/现有机制.md` / `现有地形.md` / `现有人物卡牌.md` / `现有特殊卡牌.md` / `card-image-map.md`），
>   以**行内版本标记**（如「v169 新增」）作为留痕，见 `docs/开发规则.md` 规则 2。
> - **书写口径**：缩略记录按**当时的目录结构、卡名与术语**书写（旧称「现身」「在场光环」等**保留原样**、不做追溯改写）；
>   历史路径对照：`cards-image/` → `assets/cards/`、`图片素材/` → `assets/source-art/`、
>   根目录 `game.js` 等 → `js/`、`data/现有*.md` 与 `GAME_REFERENCE.md` → `docs/`。
> - **精简说明**：每条只保留「**改了什么 / 关键口径**」，省略当时的演出细节、CSS 数值与实现过程；
>   想知道某项机制的**现行完整口径**，请看对应专项文档（本文件只回答「哪个版本引入的」）。
> - **版本号**：全局共用一条递增序列（当前最新见 `docs/开发规则.md` 规则 2），新增改动取下一个号。
> - 索引与跨模块总纲见 `docs/GAME_REFERENCE.md`（§4 文档索引内含本文件的索引条目）。
