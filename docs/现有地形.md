> **节奏（用户确认，2026 复测后统一压到 0.3s）**：逐块处理、**左→右**（按列下标升序，跳过本列与**已破碎**的列），每块两阶段 —— ① **依次摧毁该区的所有卡**（顺序＝场上放置顺序队列 `fieldQueue`，与其它摧结束算同口径；每张间隔 **0.3s**，每张播既有「分崩离析」演出 `playShatter`）→ 等 **0.3s** → ② **摧毁该地形本身**（该列变「已破碎」）；两块之间再等 **0.3s**。即整条节奏 = 卡A →0.3s→ 地形A →0.3s→ 卡B →0.3s→ 地形B。三处等待对应 `SHATTER_CARD_MS` / `SHATTER_TERRAIN_MS` / `SHATTER_NEXT_LOC_MS`（原为 1000 / 500 / 800 ms）。⚠️ 每张之间的 0.3s **短于** `playShatter` 的动画时长（约 1000ms），因此相邻几张的碎裂演出会**重叠播放**（观感＝连续爆裂）；分崩离析是**全局共用**的摧毁演出（`dw`/`dwh`/`dwb`/`purge` 等都用它），**不为一处机制单独改短** —— 想恢复“每张完整播完”把 `SHATTER_CARD_MS` 调回 1000 即可。
> **保护一律无视（用户确认）**：区域级 `prot`（睡鼠神祠）与卡级 `prot`（蕾蒂，提供区域免摧毁）、卡级 `surv`（灵乌路空，防摧毁→替代降攻）、`phx`（藤原妹红，凤凰重生回手）、`ind`（佛体金刚石，自身不可摧毁）**全部不生效、不播任何替代演出** —— 整块区域都不存在了。被摧毁的卡**照常走 `recordDestroy` 收口**：进归属方的摧毁池、并计入「纯狐」`costDown` 的摧毁计数。这与 `purge`/`dw`/`dwh`/`dwb`/`dwc` 等“会被防护拦下”的摧毁**刻意不同**，是本字段的专属口径。**含暗牌与落场 token**（石块/厄运/分身/河童…）与场上的法术一视同仁。
> **「已破碎」区域**：被摧毁的两列地形换成 `EXTRA.shattered`（`max: 0` / `wt: 0` / 无任何效果），并在 `state.locs[j].shattered` 上打标记；渲染层把**整列元素整个换掉**为 `.location.shattered-loc > .shatter-block`（**看不出原本是哪块地形、没有双方总点数的数字、也没有格位**，只写「已破碎」），`renderZones` 对该列整列跳过。效果上：`locSideMax`/`sideRoom` 恒 **0**、`locOpen` 恒 **false** ⇒ 双方（含 AI，它同样读 `sideRoom`/`locOpen`）**都不能再在该区放牌 / 移动 / 落场生成 / 复活**；`zoneTotals` 恒 0，终局 `finishMatch` **不计入赢下的区域数与三区总点数**（`playEndHighlights` 也跳过该列的放大高亮）——**只剩天界一个区域参与判定**：该区不平时按其胜负定局，该区平手则**整局平局**（赌注不变）。
> **永久锁定 + 不重复摧毁**：已破碎的列不会被卡牌 `xform` / 地形 `xformTurn` / `collapse` / 开发者「🗻 指定地形」任何一条路径再换地形（开发者工具会在弹窗内红字提示「永久锁定」）；再出现第二块带 `shatter` 的地形时，已破碎的列直接跳过，两列都已破碎则该次「降临」无事发生（只记一条日志）。⚠️ 天界**自己**（存活的那一块）照常可以被任何路径换掉（换成别的地形后新地形正常生效），但**已破碎的两列永久保持破碎**。
> **异步节奏**：整条摧毁链是一个单例 Promise，`locationRevealStage` / `locXformTurnEffects` / `locCollapseEffects` 以及 `revealRound`（每张牌后）都会 `await awaitShatterChain()` 等它播完才继续（卡牌 `xform` 那条同步路径也由 `revealRound` 补等），因此**不会与后续的「回合开始 / 翻牌 / 回合结束 / 终局结算」抢时序**；⚠️ **开发者「🗻 指定地形」例外**——`uiOnPickLocConfirm` 保持同步，启动链条后立刻关窗，演出在后台播。⚠️ 若被摧毁的那一列正是「虚假之月」，本局总回合数会**当场退回 6**（走 `syncRoundTotal`）。
> ⚠️ **回合结束结算顺序（v153）**：每回合翻牌结算后**先结算地形类效果**（`grow` 成长 / `decay` 衰减 / `dice` 定时掷骰 / `rally` 定时加成 → `purge` 摧毁 → `collapse` 崩塌，引擎入口 `runLocTurnEndEffects`），**再结算场上「回合结束」的卡牌效果**（卡牌 `fx.turnEnd`，入口 `runTurnEndEffects`），最后是手牌回合结束挂点。`collapse` 放在地形类效果的**最后**：本回合先按原地形结算，崩塌后的新地形从**下一回合**起按其规则参与。

> ⚠️ **四种“区域变形”的分工（v199；**v213** 补第四种）**：`xform`（鬼人正邪 / 灵乌路空 / 天文密葬法 / 星之仪式 的揭示）＝卡牌揭示时**指定**目标地形，且**任一方占格超过目标上限则变形失败**；**`xformR`（**v213**，1 费「梅莉」的揭示）＝卡牌揭示时**随机**目标，口径**完全沿用 `xformTurn`**（除自身、允许与另两列重复、**不做上限防御**）**；`collapse`（幽明结界）＝**回合末**按本区**卡牌张数**达标触发、目标**指定**，超限同样不崩塌；`xformTurn`（秘封俱乐部）＝**回合开始时**触发、目标**随机**，且**不做上限防御**（按上面的超限口径照常变形）。四者换地形后**都会立刻结算目标地形的「出现时」效果**（v151 口径），且**已放卡都不移动、不增删**；变形后的新地形都从**变形那一刻**起按其字段生效（`collapse` 例外：它在地形类回合末效果的最后一步，同一回合不再触发新地形的回合结束类效果）。⚠️ **v213 起 `xformR` 与 `xformTurn` 共用同一套候选收口**（`js/game.js` 的 `randomLocCandidates`）——两处随机变形的候选口径永远一致。
