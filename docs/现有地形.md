# 现有地形（区域）

> 与 `data/locations.js` 保持同步；本文件是地形（区域）的唯一权威口径（新增/修改地形只写这里，牵动引擎逻辑的字段再同步 `docs/现有机制.md`），`docs/GAME_REFERENCE.md` 只保留索引。历史变更记录见 `docs/历史版本.md`（该文件暂时停用、不再追加）。
> 引擎会执行的机制（`data/locations.js` 字段，完整口径见下表对应地形）：
> - `max` 每方放牌上限（出牌时即时限制）；`dbl` 终局该区总战力倍率；`wt` 该区计入的区域数权重（`POOL` 均 1，`EXTRA.shattered` 为 0）；`pick` 抽选权重（默认 1，辉针城 0.28）。
> - `spawn` 「出现时」双方各生成 n 张：`{card: SPECIAL 键名, n}` 指定特殊卡、`{cost, n}` 从该费用人物池抽（每张独立抽取、双方可能不同）；`reveal: true` 时生成后并结算这些卡自身的揭示效果，不写则只落地翻开（持续/时机/防摧毁等实时机制两种情况都照常）。「出现时」五条路径：① 地形揭晓；② 卡牌 `xform`；③ 地形 `xformTurn`；④ 地形 `collapse`；⑤ 开发者「🗻 指定地形」（可勾选关闭）。
> - `aff` `{group, add}` / `cb` `{c, add}` / `all` N：本区该阵营卡 / 该印刷费用的卡 / 所有卡（双方含 token）常驻 ±N，均实时。
> - `fill` N 放满 `max` 张的一方总战力 +N（实时）；`inv` 总战力低者获胜（比较取负）；`minTurn` N 第 N 回合起才可放牌；`purge` 每回合末摧毁本区「双方混比」最低战力牌（并列全删）。
> - `decay` N / `grow` N 每回合末本区已翻开卡永久 −N / +N；`gamble` N 本区翻开的卡永久随机 ±N；`gust` 本区翻开的卡在自身揭示结算完之后移到随机另一区域。
> - `dice` `{turn, n}` 第 `turn` 回合末本区所有卡各自随机 ±n；`rally` `{turn, add}` 第 `turn` 回合末本区已翻开卡 +add。
> - `collapse` `{cards, to}` 每回合末本区双方总卡牌数 ≥ `cards` 时把地形整体换成 `to`；`xformTurn` `{turn}` 第 `turn` 回合开始时把地形换成 `POOL` 中随机另一地形并结算其「出现时」。
> - `gap` N 回合末双方分别判定、把该侧可用格数 −N（缺省 1；下限 0、该侧放满则本次不加、换地形即清空）。
> - `noDown` / `prot` / `mute` 本区双方所有卡（含暗牌与 token）无法被减少战力 / 不会被摧毁 / 失去卡牌文字，见「蓬莱药局」「睡鼠神祠」「静海」；`prot` 与卡级 `prot`「蕾蒂」共用判定入口 `locNoDestroy`。
> - `extraRound` N 本地形在场时本局总回合数为 6 + N（上限 7）；`repeatReveal` 本区发生的「揭示结算」执行两次（仅揭示，不含持续与时机效果）。
> - `noReveal` 本区双方所有卡牌（含暗牌、落场 token 与法术）无法触发「揭示」效果，见「法界」；只封揭示（持续 / 时机 / 防护 / 移动与全部地形类效果照常），法术揭示不发动但照常消散，实时零状态、离开本区或换地形即恢复。
> - `shatter` 本区「出现」时摧毁另外两块地形连同其上所有卡，见「天界」与下文。
> ⚠️ 回合结束结算顺序：每回合翻牌结算后先结算地形类效果（`grow`/`decay` → `dice` → `rally` → `purge` → `collapse` → `gap` 封格，入口 `runLocTurnEndEffects`），再结算场上「回合结束」卡牌效果（`fx.turnEnd`，入口 `runTurnEndEffects`），最后是手牌回合结束挂点；`collapse` 崩塌后的新地形从下一回合起参与。
> ⚠️ 四种「区域变形」的分工：`xform`（鬼人正邪/灵乌路空/天文密葬法/星之仪式/法界之火 的揭示，`case 'xform'`）卡牌揭示时指定目标，任一方占格超过目标上限则变形失败；`xformR`（1 费「梅莉」）卡牌揭示时随机目标，口径完全沿用 `xformTurn`（除自身、允许与另两列重复、不做上限防御）；`collapse`（幽明结界）回合末按卡牌张数达标触发、目标指定，超限同样不崩塌；`xformTurn`（秘封俱乐部）回合开始时触发、目标随机，不做上限防御。四者换地形后都立刻结算目标地形的「出现时」效果、已放卡都不移动不增删，新地形从变形那一刻起按字段生效（`collapse` 例外：同一回合不再触发新地形的回合结束类效果）。`xformR` 与 `xformTurn` 共用候选收口 `randomLocCandidates`，随机候选口径一致。
> ℹ️ 「隙间」的两种来源：① 限张超限（地形揭晓成 `max < 4` 而某侧已放超上限 / `xform` 变形成更小上限的地形）——隙间数 = 4 − max(已放卡数, 该侧可用格数)；② 「八云紫的家」的回合结束封格（`gap`）。两者在引擎侧都只是“该侧可用格数减少”，只在渲染层把隙间铺在空置的不可用格，都不往 `zones` 塞卡；换地形时封格的隙间被清空、超限的隙间随新的可用格数自动重算。
> ☁️ 天界 `shatter` 口径（本区「出现」的那一刻＝上面的「出现时」五条路径）：
> - 节奏：逐块处理、左→右（按下标升序，跳过本列与已破碎列）。每块：① 依次摧毁该区所有卡（顺序＝场上放置顺序 `fieldQueue`，每张间隔 0.3s，各播「分崩离析」`playShatter`）→ ② 等 0.3s → 摧毁该地形本身（该列变「已破碎」）；两块之间再等 0.3s。三处等待＝`SHATTER_CARD_MS`/`SHATTER_TERRAIN_MS`/`SHATTER_NEXT_LOC_MS`。⚠️ 0.3s 短于 `playShatter`（约 1000ms），相邻几张的碎裂演出会重叠播放；「分崩离析」是全局共用的摧毁演出（`dw`/`dwh`/`dwb`/`purge` 等都用），不为此处单独改短。
> - 防护一律无视：区域级 `prot`（睡鼠神祠）/「蕾蒂」与卡级 `surv`（灵乌路空）/`phx`（藤原妹红）/`ind`（佛体金刚石）全部不生效、不播替代演出；被摧毁的卡照常走 `recordDestroy` 收口（进归属方摧毁池、计入「纯狐」`costDown`，与会被防护拦下的 `purge`/`dw`/`dwh`/`dwb`/`dwc` 不同）；含暗牌、落场 token 与场上法术。
> - 「已破碎」列：地形换成 `EXTRA.shattered`（`max 0`/`wt 0`），`state.locs[j].shattered` 打标记；渲染层整列换成 `.location.shattered-loc > .shatter-block`（看不出原地形、无双方总点数、无格位），`renderZones` 对该列整列跳过。`locSideMax`/`sideRoom` 恒 0、`locOpen` 恒 false ⇒ 双方（含 AI）都不能再放牌/移动/落场生成/复活；`zoneTotals` 恒 0，终局 `finishMatch` 不计入赢下的区域数与三区总点数（`playEndHighlights` 跳过该列高亮）——只剩天界一个区域参与判定：该区不平时按其胜负定局，平手则整局平局（赌注不变）。
> - 永久锁定 + 不重复摧毁：已破碎列不会被卡牌 `xform`/`xformTurn`/`collapse`/开发者「🗻 指定地形」再换地形（开发者工具弹窗内红字提示「永久锁定」）；第二块带 `shatter` 的地形出现时已破碎列直接跳过，两列都已破碎则该次「降临」无事发生（只记日志）。⚠️ 天界自己（存活那块）照常可被任何路径换掉，已破碎两列永久保持破碎。
> - 异步：摧毁链是单例 Promise，`locationRevealStage`/`locXformTurnEffects`/`locCollapseEffects` 与 `revealRound`（每张牌后）都 `await awaitShatterChain()` 播完才继续（卡牌 `xform` 由 `revealRound` 补等），不与「回合开始/翻牌/回合结束/终局结算」抢时序；⚠️ 开发者「🗻 指定地形」是唯一“不等”路径（`uiOnPickLocConfirm` 保持同步，启动后立刻关窗、后台播）。⚠️ 被摧毁的是「虚假之月」时总回合数当场退回 6（走 `syncRoundTotal()`）。引擎收口＝`startShatterChain`/`runShatterChain`/`shatterZoneCards`/`shatterZoneTerrain`/`awaitShatterChain`/`locShattered`/`renderShatteredColumn`。
> ℹ️ 阵营加成（`aff`）可用阵营（卡牌 `g` 字段）：`scarlet` 红魔馆（红美铃/十六夜咲夜/帕秋莉/芙兰朵露）、`light` 光之三妖精（桑尼米尔克/露娜·切露德/斯塔萨菲雅）。目前只有「红魔馆」带 `aff`，`light` 暂无地形加成（日后要加照 `aff: { group: 'light', add: N }` 写）。
> ℹ️ 「未揭示」地形（❓，id `unreveal`，见表格末行）：不进随机地形池（开局只从 `POOL` 抽），是每局三列地形的初始未揭示态，由地形揭晓系统在第 1/2/3 回合开始时依次揭晓为真实地形（该地形“出现时”效果在揭晓时结算；限张地形揭晓超限时卡保留、隙间只补空置不可用格，详见 `docs/现有机制.md` §2「地形揭晓系统」）。
> 其余机制需在 `js/game.js` 中扩展后才能生效。
