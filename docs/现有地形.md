# 现有地形（区域）

> 与 `data/locations.js` 保持同步。新增/修改地形后请同步本表。
> 引擎会执行的机制：`max`（每方可放张数，出牌时即时限制）、`dbl`（终局总战力倍率）、`spawn`（“出现时”给双方生成卡牌，两种写法：① `{card: SPECIAL 键名, n}` 指定特殊卡，如虹龙洞→石块；② `{cost, n}` **从该费用的人物池随机抽卡**，如妖精神社→随机 1 费卡，v165——**每张独立随机抽取**，双方可能不同；`reveal: true`（v166）表示生成后**并结算这些卡自身的揭示效果**，不写则只落地翻开、不触发揭示（持续/时机/防摧毁等实时机制两种情况都照常）。结算时机：①地形揭晓时；②区域被「区域变形 xform」变成该地形时，v151；③开发者「🗻 指定地形」替换该列时，v150 可勾选关闭）、`aff`（区域-阵营加成，常驻实时）、`fill`（放满加成：该方实际放满 max 张时总战力 +N，实时判定、被摧毁后失效）、`cb`（费用加成：该区指定费用的卡牌威力 +N，常驻实时）、`inv`（反转区域：该区总战力更低的一方获胜，比较口径取负）、`minTurn`（限回合：第 minTurn 回合起双方才可放牌）、`all`（全区修正：该区所有卡牌威力 ±N，常驻实时）、`purge`（回合结束摧毁：每回合结束后摧毁本区全场战力最低的牌，并列全删）、`decay`（回合结束衰减：每回合结束后本区**双方所有已翻开**卡牌永久 −N 战力，v153，见「间歇泉」）、`grow`（回合结束成长：每回合结束后本区**双方所有已翻开**卡牌永久 +N 战力，v155，见「寺子屋」；与 `decay` 共用同一结算函数、方向相反）、`gamble`（翻开时博彩：**在该区域翻开的卡牌**（暗牌翻面那一刻）永久随机 ±N 战力，各 50%，v156，见「驹草赌场」）、`dice`（定时掷骰 `{turn, n}`：**第 turn 回合结束时**本区**所有卡牌各自**永久随机 ±n 战力，各 50%，v157，见「骰子赌桌」；与 `gamble` 的区别：只在指定那一个回合末、一次性作用于当时在本区的全部卡，含旧卡与 token）、`rally`（定时加成 `{turn, add}`：**第 turn 回合结束时**本区**双方所有已翻开卡牌**永久 +add 战力，v161，见「演唱会」；与 `dice` 的区别：固定值、无随机；与 `grow` 的区别：只在指定那一个回合末触发一次）、`gust`（揭示后吹飞：**在该区域翻开的卡牌**在**自身揭示效果结算完之后**「若可能」移动到另一个随机区域，v162，见「魔力风暴」；与 `gamble` 的区别：结算点在自身揭示**之后**、不改本次揭示结果，且只作用于“本回合在该区被翻开”的卡）、`collapse`（回合结束崩塌 `{cards, to}`：每回合末若本区**双方总卡牌数** ≥ `cards` 就把本区地形整体换成 `to`（如冥界），v163，见「幽明结界」；变形＝该地形在本区“出现”，目标无 `spawn` 时为空操作；只会崩塌一次）、`prot`（区域免摧毁：本区域**双方所有卡牌**都不会被摧毁——`dw`/`dwh`/`purge` 等一切摧毁指向一律失效、也不触发 `surv`/`phx`，v164，见「睡鼠神祠」；与卡级 `prot`「蕾蒂」共用同一判定入口 `locNoDestroy`）、`pick`（开局抽选权重，默认 1；辉针城 0.28 ≈ 每 10 局出现 1 次）。
> ⚠️ **回合结束结算顺序（v153）**：每回合翻牌结算后**先结算地形类效果**（`grow` 成长 / `decay` 衰减 / `dice` 定时掷骰 / `rally` 定时加成 → `purge` 摧毁 → `collapse` 崩塌，引擎入口 `runLocTurnEndEffects`），**再结算场上「回合结束」的卡牌效果**（卡牌 `fx.turnEnd`，入口 `runTurnEndEffects`），最后是手牌回合结束挂点。`collapse` 放在地形类效果的**最后**：本回合先按原地形结算，崩塌后的新地形从**下一回合**起按其规则参与。
> 其余机制需在 `js/game.js` 中扩展后才能生效。
> 另有「未揭示」地形（❓，id: `unreveal`，见表格末行）：**不进随机地形池**——开局抽选只从 POOL 抽取、永不抽到它；v74 起它是**每局三列地形的初始未揭示态**，由地形揭晓系统在第 1/2/3 回合开始时依次揭晓为真实地形（含该地形“出现时”效果在揭晓时结算；限张地形揭晓超限时卡保留、隙间只补空置不可用格，详见 `docs/现有机制.md` §2「地形揭晓系统」）。
> ⚠️ **历史说明**：早期版本曾有过「圣地之巅」（赢得该区域按 2 个区域计，权重 ×2）地形，因过于影响平衡已移除；当前**不存在任何“计区加权”地形**（所有地形的 `wt` 均为 1）。
> ⚠️ **本文件是地形（区域）的唯一权威口径**（v168 起）：地形的新增/修改只写这里（牵动引擎逻辑的字段再同步 `docs/现有机制.md`），`docs/GAME_REFERENCE.md` 只保留索引、不再重复收录地形表。
> ℹ️ **阵营加成（`aff`）可用阵营（v169）**：卡牌 `g` 字段现有两个键 —— `scarlet` 红魔馆（红美铃 / 十六夜咲夜 / 帕秋莉 / 芙兰朵露）、`light` 光之三妖精（桑尼米尔克 / 露娜·切露德 / 斯塔萨菲雅，v169 三人已齐）。**目前只有「红魔馆」地形带 `aff`**；`light` 暂无地形加成（若日后要给它加地形，照 `aff: { group: 'light', add: N }` 写即可）。
