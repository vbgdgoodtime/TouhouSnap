# 联机房间服务（Cloudflare Workers）

每个房间一个 Durable Object：**只转发消息、按 (回合, 发送方角色) 去重**。
服务端不是裁判：不校验落牌合法性、不算分、不判胜负——对局在两位玩家的浏览器里各算一遍。
**不做断线重连**：刷新页面 = 离开房间，对方等提交包超时后判那一方认输。

## 部署

1. `npx wrangler login`
2. `cd worker` 后 `npx wrangler deploy`
3. 把输出里的地址填进 `js/net.js` 顶部的 `SERVER` 常量

**线上现状**：`pvp.2houvv.xyz`（自定义域名，**国内直连、不需要梯子**）。`*.workers.dev` 那个地址在国内常不稳，
只作备用 —— 别拿它做验收，也别把它写回 `SERVER`。

零依赖、无构建步骤，改完 `worker/src/index.js` 直接重新 deploy。
这个目录跟着主仓库一起版本管理；GitHub Pages 会把它当静态文件一并发布（无害，里面没有任何密钥）。

## 房间与角色

- 连 `wss://<地址>/ws/<房间码>?token=<随机串>&name=<昵称>`；房间码 6 位大写字母或数字。
- 两个角色 `host` / `guest`：先来的拿 host，后来的拿 guest；`token` 见过的角色照旧（同一个 token 重连还是原角色）。
- 两个角色都占着时，第三个连接收到 `{"t":"error","code":"full"}` 并被关闭——不挤掉房里的人。
- 断开就释放该角色：房间不保存对局状态，刷新或重开页面的人可以用同一个房间码重新进来（不会看到"房间已满"）。

## 消息

| 方向 | 消息 |
| --- | --- |
| 客户端 → 服务端 | `{"t":"msg","msg":{...}}`；`{"t":"bye"}` 按断开处理；`{"t":"kick"}` 房主把对手移出房间 |
| 服务端 → 新连接 | `{"t":"welcome","room","role","peer"}` |
| 服务端 → 对方 | `{"t":"msg","from":"host"\|"guest","msg":{...}}` |
| 服务端 → 对方 | `{"t":"peer","online":true\|false}` |
| 服务端 → 被踢的一方 | `{"t":"kicked"}`（发完就关他的连接） |

`{"t":"kick"}` 只认房主发的，且**必须由服务端关连接、不能只转发一条消息**：典型场景是对手那根连接已经半死
（他人掉线了但服务端还没察觉），只有关掉它才会触发 `gone`、把位置腾出来。被踢的一方先收到 `{"t":"kicked"}`
（好让他的界面对玩家说清是"被移出"而不是"连接断了"），随后连接被关闭、角色连同 token 一起释放。
⚠️ 客户端**当前把这个入口藏起来了**（`js/net.js` 的 `KICK_ENABLED = false`）：要用的话先把它改成 `true`、再部署这里。

`msg.t === "turn"` 的按 `回合 + ":" + 发送方角色` 去重：同一个 (回合, 发送方) 只转发第一条。
（键里用的是**发送方的角色**，不是包里的 `side`——两端各自把本地玩家当 `p`，双方包的 `side` 都是 `p`，用它做键会让两人的包互相顶掉。）
`msg.t === "start"` / `"rematch"` 到达时**清空去重表**：新一局的回合号从 1 重新数，不清会把它当成重复包静默丢掉
（症状：两端都卡在"等对手出牌"）。

除上面两条外，服务端不看消息内容、一律原样转发。客户端用到的类型：`hello`（昵称 + 头像卡图文件名 + 数据哈希 + 引擎指纹 + 卡组码）/ `ready`（准备 / 撤销，带 `ok: 1|0`）/ `start` / `turn` /
`hash`（对账指纹）/ `snap`（加倍）/ `retreat`（认输）/ `status`（我这一手交了）/ `timeout`（超时判负）/ `rematch`（再来一局）。
各条的口径见 `docs/联机对战.md` §5。

## 网络与额度

- 免费额度大致够用：官方「实时多人游戏」的用例就是 Durable Objects + WebSocket。
- 国内直连 `*.workers.dev` 常不稳（DNS 污染），所以线上绑了自定义域名 `pvp.2houvv.xyz` —— 玩家直连它即可，不需要梯子。
  换账号 / 换域名时记得同步 `js/net.js` 顶部的 `SERVER`。
