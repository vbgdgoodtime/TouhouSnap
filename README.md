# 东方逆转 · 极简网页 Demo（Marvel Snap 玩法 · 东方 Project 换皮）

纯前端、零依赖、无网络请求。双击 `index.html` 即可游玩。
仿 Marvel Snap 的玩法机制，卡牌角色与区域均以东方 Project 命名（数值/效果是原创设计，仅致敬主题）。

## 还原的核心机制

| 机制 | 本 Demo 的实现 |
| --- | --- |
| 三块区域 | 每局从 3 种区域（博丽神社/红魔馆/迷途竹林）中抽 3 块（允许重复），带限制/倍率效果 |
| 6 回合 / 能量曲线 | 能量每回合 = 回合数（上限 6），一回合可暗出**多张**牌，总费用不超过能量；能量不跨回合累积 |
| 起手保护 | 洗牌保证开局 3 张必有 1 费牌、前 4 张至少 2 张 ≤2 费，前两回合不至于无事可做 |
| 翻牌先后 | 第 1 回合随机；之后每回合按“当前领先方”先翻（判据同终局结算），双方持平则随机 |
| 暗牌不计数 | 暗牌战力不计入区域总点数，翻面后才逐张计入 |
| 现身效果 | +友军 / -敌军 / 双方+ / 落后自+ / 摧毁对方最弱卡 |
| 区域胜负 | 出现平局区域时按三区域总点数高低决胜；完全无平局时，赢下区域更多者获胜 |
| 双倍下注（Snap） | 把赌注翻倍（1→2→4→8），AI 可能跟进，终局赢家拿走赌注 |
| 认输（Retreat） | 中途认输立即输掉当前赌注 |
| 卡牌图鉴 | 顶部「📖 图鉴」查看全部 24 种卡牌，点击任意卡可放大细读效果 |
| 效果文档 | 全部地形/卡牌效果清单见 `GAME_REFERENCE.md` |

## 文件

- `index.html` — 页面骨架（依次加载 cards.js → locations.js → game.js）
- `style.css` — 界面样式（桌面/窄屏自适应）
- `game.js` — 游戏逻辑（状态机、AI、结算、渲染）；不再内置卡牌/场地数据
- `cards.js` — 全部 24 张卡的数据（新增卡牌在这里加，含可选图片字段 `img`）
- `locations.js` — 全部场地数据（新增场地在这里加）
- `cards-image/` — 卡牌图片素材目录（推荐 512×512 正方形；命名与规格见目录内 README，缺图自动回退 emoji）
- `GAME_REFERENCE.md` — 当前所有地形效果与卡牌效果的总表（游戏平衡的依据）
- `smoke-test.js` — 可选：node smoke-test.js 跑一遍无头冒烟测试（需 jsdom）

## 本地运行

直接双击 `index.html`；或起一个静态服务（如 `python -m http.server 8000`）后访问。

## 操作

1. 从手牌选一张费用可负担的卡（会高亮）；
2. 点击任意区域把它暗出（牌背显示「?」），剩余能量够的话可以继续选牌再出，直到能量用完；
3. 出牌阶段内可点顶部「能量」框**重置本回合暗牌**（确认后牌返回手牌、能量全额返还）；
4. 场地内**已翻开的敌我卡牌可直接点击放大**查看（右上角为受修正后的实时威力，下方为效果说明）；
5. 点「结束回合」交给对手（按钮固定在**右下角**），双方都出完后自动翻面、结算效果；
6. 第 6 回合结束弹窗给出胜负与立方收益。

> 每个玩家区域固定 2×2 四个卡位：第一张左上 → 右上 → 左下 → 右下，放牌不会让已有卡牌移动位置。

> 例：第 5 回合能量为 5，你可以先暗出一张 3 费牌，再暗出一张 2 费牌（同一或不同区域），然后结束回合。
> 「🏳️ 认输」固定在**左下角**；「跳过回合 / 结束回合」固定在右下角。

## 说明

- 非商业演示，仅模仿玩法结构；卡牌角色与区域为东方 Project 的同人命名致敬，数值/效果为原创。
- AI 为简单的贪心策略：评估每张卡放到各区域后的威力差，并会在优势时视情况 Snap。
