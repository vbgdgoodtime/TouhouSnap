## 1. 卡牌效果键（`k`，全部为「揭示」On-Reveal：翻面时结算一次、永久生效）

| 键 | 名称 | 说明 |
| --- | --- | --- |
| `''` | 白板 | 无效果 |
| `bf` | 同区友军增益 | 同区域**你的其他已翻开**卡牌（不含自己）威力 +N |
| `de` | 同区敌方削弱 | 同区域**对方所有已翻开**卡牌威力 −N |
| `ba` | 双方同增 | 同区域**双方所有已翻开**卡牌威力 +N |
| `bl` | 落后自增 | 本区按获胜口径落后时自身 +N（反转区域按"真实点数更高=落后"判定） |
| `dw` | 摧毁 | 摧毁同区**对方已翻开且威力最低**的一张（暗牌与 `un` 占位卡不可选为目标） |
| `spawn` | 添加石块 | 揭示：向本区域**双方**各添加 1 张特殊卡（`def.spawn` 指定，当前为石块；放满则不放） |
| `spawnO` | 敌方侧生成 | 揭示：向本区域**对方一侧**添加 1 张特殊卡（`def.spawnO` 指定，当前为厄运；对方该区放满则不放） |
| `clone` | 另两区生成分身 | 揭示：向**另外两个区域**（不含本区）**自己一侧**各添加 n 张特殊卡（`def.clone` 指定，当前为赫卡提亚的分身；该侧放满/未开放的区域跳过） |
| `switch` | 换边 | 揭示：翻开后从自己一侧转移到**对方该区域一侧**（如依神紫苑 −7 战力上对方侧；对方该区已放满则失败、留在原地） |
| `morph` | 变身 | 揭示：把自己变成**对方手牌中随机一张卡的复制体**（原卡留在对方手牌；变身后按新卡的 k 再结算一次其揭示文本；对方手牌为空则不变） |
| `gift` | 送己方最低卡 | 揭示：把本区域**己方战力最低的已翻开卡**（不含自己；并列最低随机选一）换边到对方该区域一侧（对方该区放满则失败） |
| `xform` | 区域变形 | 揭示：把本区域整体替换为目标地形（`def.xf` 指向地形 id，如鬼人正邪→`needle` 辉针城） |
| `mv` | 移走 | 揭示：把本区对方已翻开且实时战力最低的卡移到另外两区随机一处（对方该区满员/未开放的地形排除；都不可达则失败） |
| `give` | 加入手牌 | 揭示：把指定特殊卡（手牌衍生物，如废弃列车）加入自己手牌（7 张满则失败；现无卡注册，v76 起预留） |
| `dwh` | 摧毁最强 | 揭示：摧毁本区对方已翻开且战力最高的一张（平局取第一张最高者；现仅预留 token「废弃列车」自带） |
| `oc` | 对方同区落牌自增 | 揭示：翻开当回合对方曾在本区域放置过至少一张牌则此牌 +N（永久） |
| `shift` | 整体右移 | 揭示：把己方**最左侧区域**（第 1 列）**已翻开**的卡牌按放置顺序依次搬到**最右侧区域**（第 3 列）己方一侧，直至右侧己方侧填满（占格判定；暗牌不动；现仅八云紫） |

> ⚠️ 增减目标口径：所有揭示增减（`bf/de/ba`）与 `dw` 一样，**只作用于结算那一刻已翻开的卡牌**——先结算的效果不会预留给还没翻开的暗牌（后翻开的牌错过本次结算）。

**时机效果（v55，非揭示；字段 `fx`）**：卡牌 def 可声明 `fx: { turnStart, turnEnd, gameEnd }`，各条目与揭示规格同构（`k`/`a`/`spawn`/`xf`/`give`/`t`，复用 `applyEffect` 结算逻辑）。触发时机与顺序：**回合开始**（每回合最先、先于能量/抽牌）、**回合结束**（翻牌结算后、区域回合末 purge 前）、**游戏结束**（第 6 回合阶段全部结束后、结算胜负前）——全场按**场上放置顺序队列**（`state.fieldQueue`：双方卡牌放入场上的先后，谁先放谁先结算）遍历结算带该时机效果的卡。手牌打出/落场特殊卡入队；被摧毁、重置撤回手牌的卡出队（不再触发后续时机）；移动（`mv`/`fly`）不变序。当前无卡注册 fx。

**区域变形（`xform`，现仅 鬼人正邪 → 辉针城、灵乌路空 → 聚变反应炉）**：揭示把该区域 def 整体换成目标地形（含 `max`/`inv`/图标/名称）。原为限张地形时隙间格位随上限变 4 自动消失、可继续放牌；任一方现卡数超过目标上限则变形失败；不会重触发目标地形的一次性“出现时”（spawn 类）效果，`purge`/`minTurn` 等按新地形从变形起生效。

**持续效果（`og`，卡级机制，原「在场光环」）**：定义＝此牌翻开后**持续存在**的效果（一次性结算的对偶，与「揭示」互补）。带 `og: { tk, add }` 的卡（现仅「比那名居天子」，`tk:'rock'`）只要**已翻开且仍在己方场上**，己方所有带 `tk:'rock'` 标记的卡（石块）威力常驻 +N，按全场计算（不受石块所在区域/回合限制）；实时动态——源卡被摧毁/离场即消失，已加成不残留。token 用 `tk` 标记种类供持续效果匹配。

**防摧毁（`surv`，卡级防护；现仅灵乌路空 `surv:2`）**：带 `surv: N` 的卡被任何“摧毁”指向时（`dw`/`dwh`/区域回合末 purge 等）**不会离场**，取而代之**永久降低 N 点战力**（每次触发再降 N、可多次；若在聚变反应炉中反复成为全场最低会被反复降低）。被替代时不离开场上放置队列（后续时机仍可结算/继续判定）；仍可被增益等正常影响；与 `un`（绝对不可动）不同——它只是“摧毁被替换”，其余照常。

**凤凰重生（`phx`，卡级机制；现仅藤原妹红 `phx:2`）**：带 `phx: N` 的卡被任何“摧毁”指向时（`dw`/`dwh`/区域回合末 purge 等）**不会消失**——从场上移除后**返回自己手牌**并**永久 +N 战力**（每次触发 +N），可反复“摧毁→重生→再打出”并持续成长；重生瞬间从场上离开（移出放置队列），再次打出时重新暗出/翻面入队；手牌已满 7 张则重生失败、按原样被摧毁。与防摧毁 `surv` 的区别：`surv` 留在场上降战力、`phx` 离场回手并成长。

**区域免摧毁（`prot`，卡级持续机制；现仅蕾蒂 `prot: true`）**：带 `prot` 的卡翻开后、仍在自己某区域场上期间，该区域（**双方**）所有在场卡牌均无法被摧毁——引擎在任何“摧毁”指向结算前查 `locNoDestroy(locIdx)`：本区 `dw`/`dwh`（applyEffect）与回合末摧毁 `purge`（reactorPurge）直接失效、不选目标，防摧毁 `surv` / 凤凰重生 `phx` 也不会触发；保护含双方已翻开人物卡与落场 token（石块/厄运/分身等）及源卡自身。防护按源卡所在区域实时判定：蕾蒂被移去其它区域 → 原区域立即失效、新区域立即生效；**同区换边（switch/gift 类把她在本区换到对方一侧）仍在同一区域，因保护的是敌我双方，效果不变**；源卡真正离场才全场失效。

**终局离场（`leave`，卡级机制；现仅稗田阿求）**：带 `leave: true` 的卡在**游戏结束时**（第 6 回合全部阶段后、结算胜负前）**从场上消失**——它不是“摧毁”，**不触发任何摧毁相关机制**（不会触发防摧毁 surv / 凤凰重生 phx / 各类摧毁文本），永久 buff 与卡牌一起离开、不计入终局结算。若其离场使该区放满加成等实时判定变化，按既有规则自动刷新。

**大体积占格（`occ`，卡级机制；现仅伊吹萃香 `occ:4`）**：带 `occ:N` 的卡单卡占据 N 个格位（普通卡为 1）。`occ:4` 占满区域全部 4 格：**只能放进最大可放数为 4 且己方该区没有任何卡**的区域；放置/在场期间该侧视为已满（不能再落其它卡、spawn/移入等按占格口径判定；放满加成 fill 按占满 4 格计算）；卡面渲染为放大覆盖整侧 2×2；被摧毁（含反应炉等）、移走、换边、撤回或离场后自动腾出这些格位。引擎统一用 `sideUsed`/`sideRoom` 计占格，避免误用 `zone.length`。**交互口径**：换边（依神紫苑 `switch` / 因幡帝 `gift`）落到对方侧时按对方侧空余 ≥ 移入卡占格判定——对方侧被萃香占满（空余 0）则无法换边；`mv` 等把卡移往另一侧时同样要求目标侧空余 ≥ 该卡占格数（大体积卡只能移入完全空出且上限足够的一侧，即对方该区已有任何卡时萃香不能被移过去）。

**分身（`clone` 效果键，现仅赫卡提亚 → 赫卡提亚的分身）**：揭示时向**另外两个区域**（不含本区）**自己一侧**各放 1 张分身（该侧放满或区域未开放则跳过该区，两区都放不下则失败）。分身落地即翻开、占格位、进入放置队列；其战力按本体**揭示时 `cardPower`（基础+永久 buff）快照**对齐（差值记在分身的 buff 上，本体随后的增减不影响分身），分身自身之后可被增益/削弱独立修改；分身无其它效果。

**换边（`switch` 效果键，现仅依神紫苑）**：揭示后**立即把自己从一侧转移到对方该区域一侧**——翻开时若在己方一侧则消失并落到对方该区（反之同理，本规则下任何卡都在自己一侧翻开，故统一为“翻开后换到对方一侧”）；转移后卡牌归属对方（`card.side` 更新），作为对方已翻开卡参与结算（−7 战力计入对方该区），占对方一个格位，场上放置顺序不变；对方该区已放满则**换边失败、留在自己一侧**（负战力将继续计入己方）。

**变身（`morph` 效果键，现仅二岩猯藏）**：揭示时从**对方手牌随机取一张**，把自身整体替换成该卡的**复制体**（原卡仍留在对方手牌；名称/费用/威力/图标/效果/配图全部变为目标卡）。变身后**重新触发新卡的效果文本**：若新卡带 `k`（揭示）立即按其结算一次（若新卡也是变身卡则不二次变形，防死循环）；持续 `og` / 每回合移动 `fly` / 时机效果 `fx` / 防摧毁 `surv` 等由新 def 实时驱动自动生效。对方手牌为空则变身失败、保持原样。**大体积目标限制**：若随机目标是占多格的大体积卡（如萃香 occ:4），仅当**本区域 max 恰为其占格数**且**己方该区（明牌+暗牌合计）有且仅有变身者这一张卡**时才可变身，否则变身失败、保持原样（防止变身后与其他卡共存导致占格超限）。

**送己方最低卡（`gift` 效果键，现仅因幡帝）**：揭示时把本区域**己方战力最低的已翻开卡**（不含自己；多张并列最低则随机选一张）**换边**到对方该区域一侧——目标占对方一个格位、归属变对方、该卡的持续效果按新归属方生效（如把天子换边过去，会改为给新一方石块 +2）；对方该区已放满则换边失败；本区没有其他已翻开的己方卡则无事发生。

**整体右移（`shift` 效果键，现仅八云紫）**：揭示时把己方**最左侧区域**（第 1 列，下标 0）**已翻开**的卡牌**按放置顺序依次**搬到**最右侧区域**（第 3 列，下标 2）己方一侧，直到右侧己方侧**填满**为止——按占格 `occ` 判定（右侧空余 ≥ 该卡占格数才搬，右侧放满即停止）；**只搬已翻开的卡**（暗牌、`un` 卡不动）；不改变归属、揭示状态、场上放置顺序队列；移动后各区域总点数/放满加成实时重算；施放者本牌若在最左侧也会被一起搬。**演出（v78→v79）**：正常翻牌揭示结算时逐张搬运、每张间隔约 0.3s，且每张以**滑行+缩放飞行演出**落到右侧格位（`peekShiftCard`/`shiftMoveCard`/`flyCardTo`/`applyShiftReveal`）；morph/fx 等其它结算路径为一次性同步搬运。

## 2. 区域引擎字段（每条 = 一种已实装机制）

| 字段 | 机制名 | 效果 | 触发时机 | 代码入口 |
| --- | --- | --- | --- | --- |
| `max` | 限制 | 每方在本区最多放 N 张 | 出牌时即时 | `tryPlayAt` / `aiThink` / `canPlaceP` |
| `spawn` | 出现时生成 | 区域揭晓即给双方生成 `{card, n}` 特殊卡（落地翻开、占格位） | 地形揭晓时（不再开局统一结算） | `locationRevealStage()` |
| `minTurn` | 限回合 | 第 N 回合起双方才可放牌（此前锁定 🔒） | 出牌阶段判定 | `locOpen` |
| `aff` | 阵营加成 | 本区所属该阵营（`g`）的卡牌威力 +N | 常驻实时 | `locRoleBonus` / `cardPowerIn` |
| `cb` | 费用加成 | 本区费用恰为该值的卡牌威力 +N | 常驻实时 | `locCostBonus` / `cardPowerIn` |
| `all` | 全区修正 | 本区所有卡牌威力 ±N（可为负） | 常驻实时 | `locAllBonus` / `cardPowerIn` |
| `fill` | 放满加成 | 某方实际放满 max 张即该方总战力 +N；不足立即失效 | 常驻实时（按实际卡数） | `zoneFillBonus` / `zoneTotals` |
| `inv` | 反转区域 | 本区真实战力更低的一方获胜（比较口径取负，参与胜负/领先/总点数决胜） | 常驻（比较口径） | `zoneEff` |
| `purge` | 回合结束摧毁 | 每回合翻牌结算后摧毁本区全场战力最低的牌（敌我混比，并列全删；`un` 除外） | 每回合结束（含第 6 回合） | `reactorPurge` |
| `dbl` | 终局倍率 | 该区双方总战力 ×N（现无地形使用，保留字段） | 终局/展示 | `zoneTotals × dbl` |

> 角色/阵营元数据：卡牌 `g`（所属阵营键，见 `cards.js GROUPS`）、`cg`（自定义卡面色）。

**地形揭晓系统（v74，开局流程；代码入口 `locationRevealStage`）**：开局按 `pick` 权重抽定三块真实地形（互不相同）预存于 `state.locPlan`，场上三列先一律以「未揭示」占位地形（`EXTRA.unreveal`，id `unreveal`：max 4 / 无效果 / 样式同无名之丘）展示；第 **t 回合开始时揭晓第 t 列**（t=1/2/3 → 左/中/右）：①换上真实地形（max/加成/反转/purge/minTurn 等字段与列头配色即时生效）；②结算该地形「出现时」生成（`spawn`，如虹龙洞给双方石块）；③此前已放卡**不移动、不增删**。未揭示列可正常放牌（上限 4；列下提示「🃏 第 N 回合揭晓」）。**限张超限口径**：若揭晓成上限 <4 的地形（迷途竹林 max 2）而某侧已放超过上限（仅第三列可能：前两回合每侧至多放 3 张），不摧毁不移走、卡保留原格位——隙间只铺在“空置的不可用格位”，数量 = 4 − max(已放数, 上限)（放 3 张 → 1；放满 4 张或大体积卡占满 → 0；见 `buildZoneChildren` 渲染规则），此后该侧按已满处理。**换场演出（v98→v99）**：揭晓时把“未揭示”外观整列克隆到悬浮层并 **500ms** 淡出（`revealLocFade`，v99 由 700ms 调短），下方真实地形随之显形。

**换边演出（v96）**：`switch`（依神紫苑）与 `gift`（因幡帝送己方最低卡）换边时，与移动同款播放“滑行 + 缩放”克隆飞行（`flyCardTo`，通过 `pendingSwitchFly`/`flushPendingSwitchFly` 在换边后的渲染时触发，约 0.26s）。

**卡级“每回合移动一次”（`fly: true`，现仅射命丸文）**：该牌**已翻开且仍在己方场上**时，每个出牌阶段可把它移到另一区域一次——点该卡进入"选择目标区域"，再点目标列移动；目标必须未满且已开放（不点不放能量）；每回合一次（`flyMoved` 记录），下回合重置；AI 暂不使用该能力。**演出（v89）**：移动时播放与八云紫 `shift` 同款的“滑行 + 缩放”飞行克隆动画（`flyCardTo`）。

## 3. 特殊卡（`SPECIAL` 键值表，不入牌库/图鉴）

| 键 | 卡牌 | 费用 | 威力 | 生成来源 |
| --- | --- | --- | --- | --- |

## 4. 绝对不可操作卡（`un: true`，目前仅隙间）

- 无能量（c=0）、无战力（p=0），**不可移动、不可被摧毁、不可被任何效果修改**；
- 引擎防护点：区域加成 `aff/cb/all` 对它为 0；`bf/de/ba` 不会给它加/减 buff；`dw` 不可选为目标；`purge`（反应炉）不会波及它；
- 界面层它只是灰色静态格位（≋ 隙间），本就不会进 zone 数组——`un` 是数据级的保险。

## 5. 数值与比较口径（读卡力/总点数都走这里）

- `cardPower` = 基础威力 + 永久增益（buff）
- `cardPowerIn` = cardPower + 阵营加成(aff) + 费用加成(cb) + 全区修正(all)；**un 卡恒等于自身**
- `zoneTotals` = 已翻开卡的 cardPowerIn 之和 + 放满加成(fill)
- `zoneEff` = zoneTotals × dbl，`inv` 反转取负 —— 胜负/领先/总点数决胜统一用该口径
- 暗牌口径：暗牌不显示不计入总点数（翻面后计入）；揭示增减（bf/de/ba）与 dw 只作用于结算时已翻开的卡牌；AI 估值用 includeHidden 全量可见
