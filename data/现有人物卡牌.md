# 现有人物卡牌

> 与 `data/cards.js` 的 `POOL` 保持同步。人物卡按费用 1~6 放入牌库抽选池，会出现在图鉴中。
> 共 **34** 张。新增/修改人物卡后请同步本表（效果类型：白板 / bf 同区友军增益 / de 同区敌方削弱 / ba 双方同增 / bl 落后自增 / dw 摧毁敌方最弱 / spawn 添加石块 / spawnO 本区敌方侧生成特殊卡 / clone 另两区自己一侧生成分身 / give 加入手牌衍生物 / xform 区域变形 / switch 换边到对方一侧 / gift 本区己方最低已翻开卡换边到对方 / morph 变身成对方手牌随机卡复制体 / mv 移走 / dwh 摧毁敌方最强 / oc 对方同区落牌自增；另有卡级机制：防摧毁 surv、凤凰重生 phx、终局离场 leave、大体积占格 occ，见效果文本）。
> ⚠️ 0 费组（稗田阿求）**暂不入牌库洗牌**（牌库固定 1~6 费曲线），仅图鉴/开发者指定卡牌可查看/加入手牌测试；出场规则待定。
> 阵营：卡牌 `g` 字段标注所属（现仅有 `scarlet` 红魔馆）；红魔馆区域会为 scarlet 角色常驻 +2。现 scarlet 成员：红美铃 / 十六夜咲夜 / 帕秋莉 / 芙兰朵露（蕾米莉亚→中妖怪 已更名并脱离阵营）；**小恶魔（红魔馆）未实装**，占位待后续加入。
